Gmail
  1. Copy the signature.
  2. Settings → See all settings → General → Signature.
  3. Create a signature and paste normally.
  4. Choose defaults for new messages and replies.
  5. Save Changes.
  6. Send a test email and inspect the received message.
Apple Mail
  1. Copy the signature.
  2. Mail → Settings → Signatures.
  3. Select the work account and add a signature.
  4. Disable “Always match my default message font” if shown.
  5. Paste normally, preserving formatting.
  6. Set the default signature.
  7. Send a test email and inspect the received message.
  8. If formatting is lost, open the downloaded HTML in Safari and copy the rendered signature again.
